# Testo - Pizza Restaurant Menu

Приложение для отображения меню пиццерии с динамической загрузкой данных и адаптивным дизайном.

## Функциональность

- Динамическая загрузка данных через JSON-файлы
- Иерархическая навигация с категориями и подкатегориями
- Фильтрация контента по выбранной категории/подкатегории
- Адаптивный дизайн для мобильных устройств
- UI/UX элементы: лоадеры, обработка ошибок, анимации

## Технический стек

- **Frontend**: Vanilla JavaScript (ES6+)
- **Architecture**: Модульная архитектура с паттерном MVC
- **Styling**: CSS3
- **Package Manager**: npm
- **Testing**: Jest
- **Code Quality**: ESLint, Prettier

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/HamzaKotiev/testo.git
cd testo
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите локальный сервер:
```bash
npm start
```

Приложение будет доступно по адресу: http://localhost:3000

## Разработка

### Основные команды

- `npm start` - Запуск локального сервера
- `npm run dev` - Запуск сервера для разработки
- `npm test` - Запуск тестов
- `npm run lint` - Проверка кода ESLint
- `npm run format` - Форматирование кода Prettier

### Структура кода

#### AppManager
Основной класс приложения, управляющий:
- Загрузкой данных
- UI компонентами
- Состоянием приложения
- Кэшированием

#### Utils
Набор утилит для:
- Работы с кэшем
- Сетевыми запросами
- DOM манипуляциями
- Обработкой данных
- Управлением событиями

#### Constants
Конфигурация приложения:
- Константы
- Селекторы DOM
- CSS классы
- Типы данных

### Архитектура

Приложение построено на модульной архитектуре с разделением ответственности:

1. **Data Layer** - Управление данными и API
2. **Business Logic** - Основная логика приложения
3. **UI Layer** - Рендеринг и DOM манипуляции
4. **Utility Layer** - Вспомогательные функции

### Паттерны проектирования

- **Singleton** - AppManager
- **Factory** - DOMUtils
- **Observer** - EventUtils
- **Strategy** - NetworkUtils
